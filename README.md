# PLP-OOP-Assignment-wk5


# Objectives
The main goals of this project are:

1. To design and implement custom classes in Python.

2. To understand and apply constructors, attributes, and methods.

3. To explore the concepts of inheritance and polymorphism in practical applications.



# Features
# Assignment 1: Design Your Own Class 🏗️

Create a custom class with attributes and methods.

Use constructors to initialize objects with unique values.

Incorporate inheritance to demonstrate object hierarchy.

# Activity 2: Polymorphism Challenge 🎭

Define a common action method for multiple classes.

Implement polymorphism by customizing the behavior of the action method in each class.
